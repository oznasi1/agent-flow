# reach-data

Collected reach statistics for Agent Flow Deck. Generated by
`.github/workflows/reach.yml` on `main`.

This branch shares no history with `main` and must never be merged into it.

- `traffic/views.json`, `traffic/clones.json` — accumulating daily buckets. These are the
  reason this branch exists: GitHub keeps only 14 days and discards the rest permanently.
- `marketplace.jsonl` — one line per run (Open VSX + VS Marketplace counters).
- `stars.json` — full star history.
- `snapshots/referrers/`, `snapshots/paths/` — dated top-10 snapshots.
- `index.html` — the generated dashboard. Self-contained; open it directly.

See `docs/REACH.md` on `main` for how it works and how to run it locally.
